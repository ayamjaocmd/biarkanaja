Cara & Panduan Deploy Link Online

Aplikasi Ayam Betina berbasis single-file HTML ini sangat mudah dideploy secara gratis dan instan. Berikut adalah cara terbaik mendefinisikan & mendeploy link online Anda:

Metode 1: GitHub Pages (Gratis & Cepat)

  1. Simpan kode file ini dengan nama index.html.
  2. Buat Repository baru di GitHub.
  3. Upload file index.html ke root repository Anda.
  4. Masuk ke menu Settings > Pages.
  5. Pilih branch main / root lalu klik Save.
  6. Dalam 1 menit, link online Anda akan aktif (contoh: https://username.github.io/repo-name).

Metode 2: Netlify Drop / Vercel (Instan Drag & Drop)

  1. Buka situs Netlify Drop.
  2. Drag & drop file index.html Anda ke kotak yang disediakan.
  3. Netlify akan langsung memberikan link online live permanen dalam hitungan detik!

Panduan Aplikasi Ayam Betina

Tujuan Utama: Menggabungkan karakter wajah & bentuk tubuh Foto 1 dengan busana atau latar Foto 2 secara presisi tanpa mengubah identitas model.

Langkah Penggunaan:

  1. Upload Foto 1 (Karakter/Model acuan wajah & tubuh).
  2. Upload Foto 2 (Busana atau referensi latar belakang).
  3. Pilih Suasana/Tema agar pencahayaan & background selaras.
  4. Tentukan Rasio dan Jumlah Panel (1-6) yang diinginkan.
  5. Klik Generate dan nikmati hasilnya!
